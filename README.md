# Бот сети WE: утренние отчёты по ресторанам в Telegram

Каждое утро в ~09:07 по Алматы бот присылает подтверждённым получателям пакет за вчера **по каждому ресторану сети**:
дашборд дня, кассовый день, приход/расход денег, прочие расходы, закупки, изменение цен, удаления, операции кассиров,
банкеты, опасные операции, журнал событий, отзывы 2ГИС и изменения доступов. Сделан на основе бота «Хива».

Работает в GitHub Actions: сервер не нужен. Отметки об отправке и подтверждённые получатели хранятся в ветке `state`.

## Рестораны

Список — в `restaurants.json`:

```json
[
  {"slug": "restoran1", "name": "Ресторан 1", "system": "iiko", "twogis_branch_id": "",
   "settings": {"vip_tables": [], "vip_dish": "", "takeaway_section": "", "hall_sections": [], "fee_exempt": [], "routine_pairs": []}},
  {"slug": "restoran2", "name": "Ресторан 2", "system": "rkeeper"}
]
```

* `slug` — короткое латинское имя, по нему бот находит логин iiko и хранит данные.
* `system`: `iiko` — бот читает сервер iiko сам; `rkeeper` — данные придут от агента в ресторане (второй этап), пока такие рестораны пропускаются.
* `"active": false` — временно выключить ресторан.
* `settings` — необязательные проверки ресторана: VIP-столы и блюдо аренды VIP, секция выноса, залы с наценкой за обслуживание,
  блюда без наценки, рутинные пары счетов в ручных проводках. Пустые значения — проверка выключена.
* `twogis_branch_id` — ID филиала в 2ГИС для отзывов (пусто — без отзывов).

## Секреты репозитория (Settings → Secrets and variables → Actions)

| Секрет | Что это |
|---|---|
| `TG_TOKEN` | токен бота от @BotFather |
| `ALLOWED_PHONES` | номера получателей через запятую, например `77001234567,77007654321` |
| `ALLOWED_USERNAMES` | (необязательно) логины Telegram без @ через запятую |
| `IIKO_ACCOUNTS` | логины iiko всех ресторанов одной строкой JSON: `{"restoran1": {"url": "https://restoran1.iiko.it:443", "login": "report", "password": "..."}}` |

Для iiko лучше завести отдельного пользователя только с правами на отчёты. Каждое подключение занимает лицензию iiko, бот всегда выходит из сессии.

## Запуск

1. Создать бота в @BotFather, добавить секреты.
2. Получатели открывают бота, нажимают `/start` и «Поделиться номером» (принимаются только номера из `ALLOWED_PHONES`).
3. Проверка вручную: Actions → «Отчёты WE» → Run workflow → `morning --all --force` или `morning --restaurant restoran1 --date 2026-11-09 --force`.

Сообщения боту обрабатываются раз в 30 минут (`.github/workflows/updates.yml`): так бот укладывается в бесплатные минуты GitHub Actions.
Команды в чате: `/reports`, `/report deletions [дата] [ресторан]`, `/dashboard [дата] [ресторан]`, `/day [дата] [ресторан]`, `/status`.
Без ресторана отчёт приходит по всем ресторанам.

Локально: скопировать `.env.example` в `.env`, затем `python run.py morning --all --date 2026-11-09`.
Без `TG_TOKEN` всё работает в сухом прогоне: сообщения печатаются и складываются в `outbox/`.
